# 💜 PHP - Um Universo de Conhecimento

Seja bem-vindo ao meu projeto de estudo e documentação sobre **PHP**!  
Aqui você encontra uma coletânea de conteúdos essenciais para quem quer entender ou relembrar os principais conceitos dessa linguagem poderosa.

## 🌌 Visão geral

Este projeto é apresentado em formato web, com um visual espacial inspirado no universo, tornando a navegação mais agradável e imersiva.  
Nele, você encontrará páginas dedicadas a diversos tópicos fundamentais do PHP, com explicações claras e organizadas.

## 🧑‍💻 Assuntos abordados

- **Comentários** — Como documentar e explicar seu código PHP.
- **Variáveis** — Estruturação e uso de variáveis.
- **Saídas** — Formas de exibir dados no navegador.
- **Entradas** — Manipulação de dados inseridos pelo usuário.
- **Laços de repetição** — Estruturas de repetição e exemplos práticos.
- **Arrays** — Como trabalhar com arrays no PHP.
- **Funções** — Definição e utilização de funções.
- **Classes** — Introdução à programação orientada a objetos no PHP.
- **Exceções** — Tratamento de erros e exceções.
